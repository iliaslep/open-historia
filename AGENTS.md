# Правила продолжения разработки

## Начало сеанса и объём

Сначала прочитай PROGRESS.md и ближайший незавершённый участок ROADMAP.md.
GAME_DESIGN.md — согласованные требования; ARCHITECTURE.md — решения и точки
расширения. Полный исходный промт уже сохранён в Codex_Geopolitical_Strategy_Prompt.md.
Не перечитывай весь проект без необходимости. Команда «Продолжай разработку по
ROADMAP.md» означает выполнить ближайший ограниченный участок и проверить его.
По текущему указанию пользователя продолжай последовательные участки без промежуточного подтверждения. После проверки и фиксации участка переходи к следующему, сохраняя прогресс. Не используй субагентов без отдельного запроса.

Используй существующий checkout: облачная задача уже изолирована. Не создавай
Git worktree без явного запроса пользователя. Перед правками проверяй git status
и сохраняй чужие изменения. Не меняй зависимости/lockfile ради случайной уборки.

## Разработка

- Сохраняй React/Vite/Express, карту, редактор и библиотеку партий.
- Новые расчёты делай чистыми, типизированными и детерминированными.
- LLM предлагает команды; только движок разрешает и применяет изменения.
- Не выдавай AI-показатели за факты. Храни источники, единицы и игровые допущения.
- Не объявляй автономную игру готовой, пока нет настоящего хода без сети/ключей.
- Сохраняй прежние партии; новые поля проверяй через нормализацию, API и экспорт.
- Используй существующие механики до создания параллельной реализации.
- Русский UI/повествование; новые строки согласуй с имеющейся системой i18n.
- Сохраняй LICENSE/атрибуции, отдельно проверяй карты и другие данные.
- OAuth реализуй только по проверенным официальным условиям. Не извлекай
  cookie, токены ChatGPT/Codex или значения секретов из окружения.

## Проверка в облачной среде

Подготовлены Node 24, node_modules, dist, карты и fmg. Процессы после восстановления
снимка нужно запустить снова. Рабочая директория — корень этого репозитория.

```bash
export NODE_USE_ENV_PROXY=1
export NO_PROXY="${NO_PROXY:+$NO_PROXY,}$(node --input-type=module -e 'import os from "node:os"; console.log(Object.values(os.networkInterfaces()).flat().map(x=>x.address).join(","))')"
export no_proxy="$NO_PROXY"
npm test
npm run build
```

Обе формы no_proxy нужны, чтобы LAN-тесты обходили прокси. Не выводи секретные
значения окружения. Установка при необходимости:
`ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci --cache /workspace/.npm-cache --no-audit --no-fund`.
Не исключай все optional packages: они включают платформенные зависимости Vite.
Это установка для веб/серверной разработки, не проверка Electron-пакета.

Запуск: `OH_HOST=127.0.0.1 PORT=3000 node server/server.js`; отдельный терминал:
`npm run dev -- --host 127.0.0.1`. Проверяй HTTP, содержимое API и byte ranges карт,
а не только порт/PID. Не представляй localhost как общедоступный preview.

Сначала запускай целевые тесты. Для общих контрактов — полный npm test и сборку.
Глобальный lint имеет исходные ошибки (см. PROGRESS.md); проверяй изменённые файлы
отдельно и не исправляй весь репозиторий попутно. Не отключай проверки ради зелёного отчёта.

Для изменений IndexedDB запускай `node --test src/runtime/web/simulationClock.browser.test.js`.
Тест использует настоящую IndexedDB двух вкладок Chromium без npm-драйвера.
По умолчанию нужен `/usr/bin/chromium`, другой путь задаётся через CHROMIUM_BIN.
Без браузера тест явно пропускается; Map-подмена в libraryStore.test.js не
подтверждает межвкладочную транзакционность. Для веб-backend также проверяй build:web.

## Завершение

Обнови PROGRESS.md: изменения, реально проверенное, ограничения и следующий шаг.
Создай отдельный локальный коммит только с работой сеанса; не push/merge/publish
без запроса. Сообщи кратко результат, тесты и следующий минимальный участок.
Указывай оставшиеся TODO, неудачи и непроверенные функции раздельно.
