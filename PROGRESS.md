## Текущий результат — продолжать отсюда

0.2.1 — исправление ответа/зависания чата. Подтверждены две регрессии: ожидание
EOF после уже полученного response.completed; raw Failed to fetch при обрыве
после terminal event. Новые тесты сначала воспроизвели оба отказа. Теперь
успех определяется terminal event, канонический текст берётся из completed
output при его наличии; сокет закрывается без ожидания. Обрыв ДО completion
никогда не превращается в частично исполняемую команду. JSON/body отказы имеют
безопасные stage-коды. Статический catch вокруг headers больше не оставляет
ошибки чтения тела без обработки.

UI loopback-запросы ограничены по времени, включая чтение JSON. Сбой отправки
отличается от отказа OpenAI: [local:request/response/timeout] и [network:...]
[stage:...]. После ошибки чата обновление партии идёт в фоне; его зависание
не удерживает busy. Устаревший фоновый snapshot не перезаписывает более новую
revision. В Chromium воспроизведены failed POST + бесконечный refresh; кнопки
снова доступны. Нет автоматического повторения платного запроса.

Windows UI использует direct-сессию для локального сервера; ChatGPT вынесен
в отдельную system-proxy сессию. TLS не отключался, cookies не заимствуются.
Добавлен check-strategy-network.cjs: настоящий Electron main process, локальный
synthetic HTTP provider/proxy, обычный/не закрытый/оборванный SSE, отказ от
partial и доступность loopback после сетевой ошибки. Проверка входит в Windows
CI и пишет release/native-network-check.json; её результат требуется до релиза.
Локальный npm test: 3011 passed, 0 failed, 0 skipped, 2 прежних TODO.
Это воспроизводимые исправления; точная причина на машине пользователя ещё
не подтверждена. Новые задачи пользователя: миграция населения, разведка по
механикам Open Historia, предложения решений и обновление native UI. После
проверки hotfix продолжать их без промежуточного подтверждения.


Версия 0.2.0 — чаты, влияющие на игру (2026-10-25). Добавлены основной «Чат
решений» и отдельная дипломатическая беседа с выбранной страной. Используется
существующий storage/chat.json, форма legacy threads/messages сохранена;
прежние беседы не перезаписываются. У новых threads engine=native-strategy-v1.
Хранятся 32 недавние беседы по 40 реплик, контекст ИИ — последние 10 реплик
только выбранной беседы и её исполненные результаты.

LLM через официальный Responses возвращает reply/stance/actions. Проверяются
JSON, до трёх действий, типы/суммы/адресаты и компетенции. Кабинет работает с
базовыми налогами, расходами, инфраструктурой, резервами, помощью, торговлей,
санкциями, разведкой, войной и перемирием. Делегация может отказаться или
предложить встречные условия; не командует внутренними ведомствами чужой
страны. Ей не передаются бюджет/готовность игрока, тайные доклады кабинета
или другие переговоры. Неподдерживаемые реформы/альянсы/передача территорий
должны приводить к уточнению, а не к выдуманному результату.

Сообщение сохраняет предложение и расчётную цену, не меняя экономику.
«Принять и выполнить» / «Принять условия» применяют его через движок.
Любой другой ход/решение делает старое предложение неисполняемым. Проверяются
поддержка, деньги, сроки и согласие страны по правилам; весь пакет применяется
целиком либо не применяется. Время не идёт, RNG не расходуется. Добавлен
дипломатический сигнал: ±2 отношений, 2 поддержки, не чаще раза в день со
страной. Его cooldown хранится в optional strategy.contacts и валидируется.

Операции chat-record/chat-apply атомарно фиксируют чат, game/world и метаданные.
Для них journal schema /2 (старый клиент отказывается его восстанавливать);
старые /1 остаются читаемыми. В IndexedDB чат входит в ту же readwrite
транзакцию games+gameMeta. Импорт повреждённой native-переписки отказывается
до записи. После сетевой ошибки UI перечитывает партию, учитывая возможный
уже зафиксированный journal.
