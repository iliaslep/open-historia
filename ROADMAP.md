# Поэтапный план

Правило сеанса: ближайший незавершённый ограниченный участок, проверка,
обновление PROGRESS.md, отдельный локальный коммит и остановка на логичной границе.
Не выполнять все этапы сразу. `[x]` означает проверенный результат, `[ ]` — работу.

## Этап 0 — аудит и подготовка

- [x] Исследовать основной и альтернативный репозитории, выбрать базу.
- [x] Установить зависимости, скачать и проверить карты, собрать приложение.
- [x] Проверить CI-тесты, HTTP/API и Vite API proxy; зафиксировать исходный lint.
- [x] Сохранить полные требования и пять постоянных проектных документов.
- [x] Проверить доступность официальных SIWC-источников; записать сетевой блокер.
- [ ] Прочитать SIWC-документы после открытия доступа и подтвердить применимость.

Разработка программного ядра не зависит от последнего пункта. Аудит интеграции
остаётся незавершённым, его нельзя обозначать как подтверждённую поддержку Plus.

## Этап 1 — рабочее ядро

- [x] Небольшое исправление offline-статуса обновлений и независимые от сети тесты.
- [x] Контракт заголовка расчётного состояния, версии, явное создание и PRNG.
- [x] Подключение через существующие нормализаторы и сохранения с round-trip тестами.
- [ ] Переключение исполнения старых/новых партий на соответствующий движок.
- [ ] Минимальный автономный ход: 1/7 дней и календарный месяц на общей функции дня.
- [ ] Один программный тип решения NPC с измеримым ресурсным ограничением.
- [ ] Реальный путь UI → ход → сохранение → загрузка → карта/показатели.
- [ ] Атомарная фиксация хода/восстановление при сбое и отсутствие изменений на паузе.

Приёмка: новая партия проходит ход без сети и ключа, NPC меняет состояние по
правилам, загрузка даёт тот же следующий ход; старая партия не теряет поля.
Следующий минимальный участок — чистая функция продвижения времени с общей
обработкой дня, revision и согласованием даты заголовка с игровой датой.
Затем отдельным участком подключить её к реальному пути UI и добавить решение NPC.
Не начинать одновременно экономику, OAuth и новые панели.

## Этап 2 — экономика

- [ ] Единицы и происхождение данных, формулы потоков, бюджет/долг/проценты.
- [ ] Торговля, отрасли, энергетика, инвестиции и потребление.
- [ ] Налоги/расходы/реформы с ценой, процедурой и задержкой.
- [ ] Русская бюджетная панель на расчётных данных; убрать LLM-запись этих величин.

Приёмка: проверены балансы, обе стороны торговли, пределы, округления,
несостоятельность, санкции и сценарии роста/спада. Ни NaN, ни скрытых денег.

## Этап 3 — дипломатия

- [ ] Стратегические интересы, доверие, репутация и автономная оценка предложений.
- [ ] Реестр договоров, встречные предложения, ратификация, сроки и нарушения.
- [ ] Многосторонние встречи, посредники, организации и мирные урегулирования.

Приёмка: торговый договор меняет расчёты обеих сторон, отклонённый ничего не
меняет, нарушение даёт предусмотренные последствия; союз не отменяет институты.

## Этап 4 — политики и советники

- [ ] Проверенные персонажи/должности/периоды, учреждения Германии и полномочия.
- [ ] Парламент, партии, коалиция, выборы, общественное мнение и отставки.
- [ ] Шесть форматов совещаний, разные компетенции и память решений.

Приёмка: реформа может быть отклонена процедурой; смена власти меняет полномочия;
советник не знает скрытых данных и будущего. Диалоги помечены реконструкцией.

## Этап 5 — разведка

- [ ] Расширить существующие spycraft/reports: бюджет, сеть, срок, риск, достоверность.
- [ ] Контрразведка, ошибочные сведения, обнаружение и дипломатические последствия.

Приёмка: отчёт меняет доступную информацию, не раскрывая точную истину; операция
не выполняется без ресурсов, её результат воспроизводится после загрузки.

## Этап 6 — военная система

- [ ] Снабжение, логистика, мобилизация, промышленность, боеготовность и потери.
- [ ] Связь с бюджетом, географией, договорами и существующими картографическими ops.
- [ ] Перемирия и мир; контроль, суверенитет и претензии не смешиваются.

Приёмка: неподдерживаемая снабжением армия теряет возможности; мирный договор
останавливает конфликт; территория после сохранения совпадает с отображением.

## Этап 7 — необязательная LLM-интеграция

- [ ] Закрыть SIWC-проверку из этапа 0. Реализовать только официально разрешённый путь.
- [ ] Проверяемые команды из свободного текста, персонажи и переговоры на паузе.
- [ ] Контекст по области знания, память, лимиты, кэш и подтверждение дорогих запросов.
- [ ] Отказ сети/лимита/авторизации возвращает программный режим без потери хода.

Приёмка: невалидный LLM-ответ не меняет мир; официальный вход либо проверен
end-to-end, либо честно недоступен. Без него базовая игра остаётся работоспособной.

## Этап 8 — сценарий и полировка

- [ ] Исторические источники для Германии 2016-12-08, политиков и исходных отношений.
- [ ] Разделение фактов/оценок/балансных параметров; проверка территории и институтов.
- [ ] Русские панели, адаптивность, визуальная карта, баланс, инструкция локального запуска.
- [ ] Длинная партия, повреждённые/старые/будущие сохранения, миграции и экспорт/импорт.
